---
title: 9 - Terminology
sidebar_position: 9
---

- **Product**: A course, consultation, or download package.
- **USER**: Canonical API role for normal consumers of creator content. Public signup and first Google sign-in create this role by default.
- **CREATOR**: Canonical API role for users who can publish products.
- **ADMIN**: Canonical API role for admin users. Admins can access creator sections during Phase 1.
- **Library**: User-owned products (purchased or assigned).
- **Wishlist**: User-saved items for later.
