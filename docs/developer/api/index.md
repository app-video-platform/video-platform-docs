# API Service Index

The frontend API layer lives under `src/core/api`.

Use [Frontend API Reference](../frontend-api-reference.md) as the high-level entry point. The files in this section provide domain notes for service wrappers that are currently used by the frontend.

## Service domains

- [HTTP Client](./http-client.md)
- [Auth API](./auth.md)
- [User API](./user.md)
- [Products API](./products.md)
- [Calendars API](./calendar.md)

Admin and Reviews services also exist in the frontend, but this section has not yet been split into dedicated pages for them.
