# Audit Logs

## Overview

Audit logs help Administrators review admin role changes and admin product management actions.

The current Audit area presents a paginated table with filters for finding entries by action, target type, or target ID.

## Who can use this

This page is for Administrators.

## What you can do

Administrators can:

- View audit log entries.
- Filter entries by action.
- Filter entries by target type.
- Filter entries by target ID.
- See when an entry was created.
- See the actor user ID.
- See the action performed.
- See the target type and target ID.
- Review before and after summaries when available.
- Move between audit result pages.

## How it works

The Audit page loads admin audit entries into a table. The filter fields refresh the results and return the table to the first page.

Each row shows the time of the action, the actor, the action name, the target, and before/after summaries. If a before or after summary is not available, the table shows a placeholder dash.

## Current limitations

- The Audit area shows user IDs and target IDs rather than full linked detail views.
- Filters are text fields; the UI does not provide predefined action or target-type lists.
- The page documents admin audit visibility only. It does not provide audit export, retention controls, or audit log editing.
