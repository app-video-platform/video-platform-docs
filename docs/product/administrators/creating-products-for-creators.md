# Creating Products for Creators

## Overview

Administrators can create a product on behalf of a Creator.

The Admin-specific part of the workflow is choosing which Creator will own the product. After that, the product uses the same product creation and builder experience documented for Creators.

## Who can use this

This page is for Administrators.

## What you can do

Administrators can:

- Open the Admin Products area.
- Select a Creator owner from the creator owner list.
- Start product creation for that Creator.
- Choose a product type.
- Create backend-persisted Course, Download, Consultation, or Membership products.
- Continue into the shared product builder.

## How it works

From the Admin Products page, choose a Creator owner and select **Create product**. Product creation opens with the selected Creator as the owner.

The Admin then chooses a product type and enters the initial product title. Once the draft product is created, the shared builder opens. From there, Admins can configure the same product areas Creators use: basics, pricing, media, and the product-type-specific sections.

## Current limitations

- Admin-created products inherit the current product-builder limitations.
- The backend accepts Admin-created Products only when the selected owner exists and has exactly the Creator role.
- Product Media and publication validation are persisted. Course/customer content consumption still has incomplete areas.
- Membership authoring is persisted, but binary media, publishing,
  subscriptions, checkout, entitlements, and member access are unavailable.
- The Admin creation flow requires selecting a Creator owner before starting.
