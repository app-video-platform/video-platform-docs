# Admin Overview

## Overview

The Admin area is for managing platform users, products, and admin audit history.

Administrators have broader access than Creators and End Users. They can manage users across the platform, work with products owned by creators, create products for creators, and review logged admin activity.

## Who can use this

This page is for Administrators.

Only users with the Administrator role can access the Admin area.

## What you can do

Administrators can:

- Open the Admin dashboard.
- Manage users.
- Search and filter users.
- Change a user's platform role.
- Manage products across creators.
- Search and filter products.
- View, edit, and delete products.
- Create products for a selected creator.
- Review admin audit logs.

## How it works

The Admin dashboard links to three main areas:

- **Users**: search users and change their single platform role.
- **Products**: view, edit, delete, and create products for creators.
- **Audit**: review admin role changes and product management actions.

Admin product management uses the same product builder used by Creators. The Admin-specific difference is that an Administrator can choose the creator who owns a new product.

## Current limitations

- Admins can change a user's role, but the UI does not expose custom permissions or bulk user actions.
- Admin product editing inherits the same product-builder limitations documented for Creators.
- The Admin area does not provide a complete publishing, checkout, payment, or entitlement workflow.
