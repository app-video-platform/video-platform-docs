# BUG-011 — Authentication pages overflow narrow viewports

- Severity: Medium
- Status: Confirmed; not fixed in this test execution pass
- Related case: UX-015
- Role: Guest
- Environment: deployed frontend; independent browser session

## Reproduction

1. Open `/auth/login` as Guest.
2. Set the viewport to 320, 375, or 768px wide.
3. Inspect form fields and actions without horizontal scrolling.

## Expected

The sign-in form and its actions fit the viewport, with input contents and controls readable and reachable.

## Actual

Document width remains800px at each of these widths. Email and Password fields extend beyond the screen. At320px, the password visibility and Forgot Password controls are outside the initial viewport. The page fits1440px.

## Scope and limits

The observed issue concerns layout and control reachability. It does not establish a password or Google sign-in failure.
