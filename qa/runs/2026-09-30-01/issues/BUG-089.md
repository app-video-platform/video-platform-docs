# BUG-089 — Sign-in validation errors are not associated with their inputs

- Severity: Medium — custom validation feedback is visible but not exposed through the affected input.
- Status: Confirmed in the deployed Guest sign-in form on 31 October 2026.
- Case: UX-016.

## Reproduction and actual result

1. Open `/auth/login` as Guest. Use Tab and keyboard input to enter an invalid email and a dummy password; reach Sign in and press Enter.
2. `Invalid email format` appears, but Email has neither `aria-describedby` nor `aria-invalid`. The form's error paragraph is not referenced by the field. Focus remains on Sign in; no populated alert/live region contains the error.
3. Clear the dummy password, correct the email syntax by keyboard, and submit with Password still empty.
4. The email error clears and `Password is required` appears. Password likewise has neither an error description reference nor invalid-state attribute.

Both inputs have associated visible labels. This issue concerns custom error association, not missing field names. The separate registration and recovery forms use native required/email validation in the measured negative paths; they are not classified as failing merely because these ARIA attributes are absent.

## Expected

The custom invalid state and visible error are programmatically associated with the affected input, so users can identify and revisit that field's validation feedback.

## Implementation and scope

The current SignIn component uses `noValidate`, renders error paragraphs separately, and does not pass its error strings to the shared Input/PasswordInput controls. Shared Input creates an error ID, description reference and invalid attribute when given its `error` prop. This is consistent with the deployed DOM; the deployed revision was not independently identified.

No screen-reader speech, valid login submission, reset request or provider action is claimed. Only dummy invalid values were used, and the original synthetic Creator session was restored afterward. No implementation change was made.
