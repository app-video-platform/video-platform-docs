# BUG-070 — Consultation Overview renders unset buffers as “null minutes”

- Severity: Low — visible invalid field presentation.
- Status: Confirmed in the deployed browser; not fixed in this testing pass.
- Case: PROD-006.
- Role: synthetic Creator owner.
- Fixture: Consultation `89f19565-c4cd-42ac-9c3d-0861f760685b`.

## Reproduction

1. Open the management Overview for a Consultation whose API details contain null `bufferBeforeMinutes` and `bufferAfterMinutes`.
2. Inspect Consultation setup.

## Expected

Unset optional buffers use the Overview’s empty-value presentation; the page does not display a literal null value as a duration.

## Actual

Both Buffer before and Buffer after display `null minutes`. The API confirms both fields are null. Duration30 minutes, Phone, Draft and Free render separately as supplied.

## Implementation and evidence

`product-overview.component.tsx` checks each buffer only against `undefined`, then interpolates its value with `minutes`; null passes that check. The consolidated evidence packet `deployed-consultation-weekly-range-matrix-and-overview-null-fields-2026-10-23` includes the API oracle, browser text and source snapshot/hash.

No buffer values or application implementation were changed. The separate weekly-range test restored the synthetic Product’s original logical fields; its update timestamp reflects its successful preliminary control.
