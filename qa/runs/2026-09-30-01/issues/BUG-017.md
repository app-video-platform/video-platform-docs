# BUG-017 — Landing Marketing description has no accessible field name

- Severity: Low
- Status: Confirmed; not fixed in this test execution pass
- Related case: UX-016
- Role: CREATOR

## Reproduction

1. Open the synthetic Course landing builder.
2. Inspect the Marketing description textarea using the accessibility tree or label associations.

## Expected

The textarea has a programmatic name matching its visible Marketing description label.

## Actual

The visible label text is followed by an unnamed textbox. The textarea has no id/name, associated labels, aria-label or aria-labelledby. Assistive tools cannot identify the field from its visible label.

## Evidence

- [Field attributes and accessibility snapshot](../evidence/landing-marketing-description-label.json)
- [375px landing builder](../evidence/landing-builder-375px.jpg)

No field value or saved landing configuration was changed. Other forms remain separate variations.
