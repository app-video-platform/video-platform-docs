# BUG-087 — Marketing navigation clips Contact and account actions on narrow screens

- Severity: Medium
- Status: Confirmed; not fixed in this execution pass
- Related case: UX-015
- Roles: Guest and synthetic User, Creator and Admin (observations below)
- Environment: deployed frontend, 29 October 2026

## Reproduction

1. Open `/`, `/about`, `/pricing`, `/getting-started`, `/contact`, `/features`, `/help`, or `/demo`.
2. Wait for the signed-in navigation to show **Go to Dashboard**.
3. Set the viewport to 320px or 375px wide.
4. Inspect Contact Us, Go to Dashboard and the account control before horizontal scrolling.

## Expected

Marketing navigation adapts to the narrow viewport so users can reach its actions without horizontal scrolling.

## Actual

The initial Creator measurements show that all eight routes retain a horizontal navigation row. Contact Us spans approximately x339–398, Go to Dashboard x398–471, and the account control x483–625. These actions are outside the initial 320px view; Contact is partially outside at375px, with Dashboard and account entirely outside. There is no visible collapsed navigation control in the observed accessibility tree.

Settled document widths are approximately625px for six routes,762px on About and1062px on Home at320/375px. The larger Home/About extents also include page content; this issue does not assign all overflow to the navigation.

At768px the measured navigation controls fit; Home and About still have larger document extents requiring separate investigation. All eight measured documents fit1440px. Pricing's Previous/Next controls and Demo's reset action work by keyboard at all four widths, so this is not a claim that all narrow-screen actions fail.
