# BUG-074 — Upload error remains after a successful retry

- Severity: Low — stale failure feedback contradicts completed uploads.
- Status: Confirmed; not fixed.
- Case: FILE-003.
- Environment: unchanged frontend upload flow against the development API and real DigitalOcean Spaces. A declared file-input driver selects synthetic text files; a restricted loopback proxy independently fails presign, storage PUT or confirmation before forwarding that step. Storage success forwards real bytes to Spaces. This is not a deployed CORS or native file-picker test.

## Reproduction

1. Open the synthetic Draft Download's file section.
2. Select a small synthetic text file and force one upload step to return 503.
3. Observe the failure alert and no new persisted metadata row.
4. Restore the dependency and reselect the same file using the visible test driver.
5. Observe the uploaded file row after real presign 200, storage PUT 200 and confirmation 201.

## Expected

A successful retry clears the obsolete upload failure feedback.

## Actual

The prior presign, PUT or confirmation failure alert remains beside the successfully uploaded row. All six variants reproduce this: three with Creator API authority and three with Admin API authority. The local frontend retains the originally loaded Creator profile; this does not claim an Admin browser-navigation matrix.

Fresh API and read-only SQL prove exactly one private metadata record per successful retry. Authorized download GETs return the exact uploaded bytes for all six files. No false metadata completion or duplicate row was found. After a failed confirmation, an uploaded object may remain; cleanup was not assumed or attempted.

Consolidated evidence packet `hybrid-upload-three-stage-retry-and-deployed-reload-2026-10-26` contains browser observations, restricted request traces, private-file metadata and byte hashes. Six harmless files and their Draft remain for future testing. The synthetic account's original Creator role and full profile were restored. No application source was changed.
