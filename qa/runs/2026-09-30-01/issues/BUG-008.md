# BUG-008 — Profile Save ignores field validation

Severity: Medium. Case PROF-005. OWNER-A, CREATOR. Deployed revisions unknown.

## Reproduction

1. Open Settings → Profile.
2. Enter a 29-character Bio, blur the field, and click Save.
3. Repeat with a 9-character Tagline and malformed Website (`not a website`).
4. Repeat with Bio length 251 and Tagline length 121.

Expected: local minimum/maximum/URL validation displays errors. Actual: no errors appear; Save shows `Product created successfully!`. The Bio counter displays 251 / 250.

Evidence: [invalid values](../evidence/profile-invalid-values.json), [upper boundaries](../evidence/profile-upper-boundaries.json). The current local Profile component defines Bio 30–250, Tagline 10–120, and website validation, but Save directly displays a toast rather than submitting validation. This is a source hypothesis for the deployed behavior; deployed revision is unknown.

Profile persistence is a separate cataloged limitation. These observations establish missing local validation, not a successful profile mutation. Reload cleanup is recorded in the results ledger.
