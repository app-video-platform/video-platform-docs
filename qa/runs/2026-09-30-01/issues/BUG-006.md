# BUG-006 — Wishlist dropdown Add to cart does not add the item

- Severity: Medium
- Case: CART-018 / user-dropdown-add-does-not-add
- Deployment versions: unknown
- Role: USER
- Fixtures: Download B in Wishlist; Consultation in Cart

## Reproduction

1. Add `QA-2026-09-30-01 Download B` to Wishlist from Explore while it is absent from Cart.
2. Open the navbar Wishlist dropdown.
3. Click Add to cart for that Download.
4. Inspect Shopping Cart.

Expected: the selected Download is added. The catalog marked this mismatch for investigation; the visible action label establishes the expected action.

Actual: navigation opens Shopping Cart, which still contains only the existing Consultation at €15. Download remains in Wishlist. No purchase or entitlement is created.

Control comparison: Go to wishlist, then Move to cart adds Download and removes it from Wishlist. Cart then contains Consultation + Download, total €27.5. This is a working alternative.

Evidence: [dropdown item absent from displayed Cart](../evidence/wishlist-dropdown-no-add.jpg).

Initial reproduction: once, followed by the successful Library comparison. No server content changed. Clear synthetic local collection entries after completing Cart variations.
