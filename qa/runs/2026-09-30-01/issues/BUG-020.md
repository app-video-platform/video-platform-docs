# BUG-020 — Quiz question labels target the first question's fields

- Severity: Low — label activation and accessible field names are incorrect.
- Status: Confirmed; no implementation changes.
- Case: UX-016.
- Role: OWNER-A, CREATOR.
- Deployment version: unknown; observed 1 October 2026.
- Course: `cb045295-cf70-445c-99a7-46fc0618e58e`.
- Quiz lesson: `37dbef65-eb38-48ce-b4f9-2a7b913c8bca`.

## Reproduction

1. Open the Quiz editor and add a second question.
2. Switch to Manual Split.
3. Click the second question's Points label.
4. Inspect both Points and Explanation label associations.

Expected: every question field has a unique ID and its own label. The second question's label focuses the second question's input.

Actual: both Points inputs use `id=points`. Both Points labels associate with the first input; the second has no associated label. Clicking the second label focuses the first input. The two Explanation fields likewise reuse `id=explanation`, leaving the second field without an associated label.

## Evidence and diagnosis

- [Field IDs, associated labels and observed focus](../evidence/quiz-question-label-targets.json)

The local QuestionCard uses shared fixed field names `points` and `explanation`, consistent with this behavior. The deployed revision is unknown.

Cleanup: no field value changed during label-targeting observation. The two local questions are synthetic.
