# BUG-001 — Saved product editing workspaces render blank for all four types

- Severity: High — saved authoring workspace unavailable on reload.
- Cases: PROD-008 / COURSE create/reload; PROD-011 / COURSE canonical edit reload.
- Deployment versions: unknown; observed deployed frontend on 30 September 2026 at 09:56 UTC.
- Account: OWNER-A, CREATOR.
- Fixture: ddd5bb80-183e-48d5-84cd-8819ca082a58.

## Reproduction

1. Open Products and Add product.
2. Leave Course selected, enter QA-2026-09-30-01 Course and submit once.
3. Observe new edit route, Draft status and Basics workspace.
4. Reload /app/products/edit/ddd5bb80-183e-48d5-84cd-8819ca082a58.

Expected: same saved Course workspace loads. Actual: blank page with no application controls. Browser console reports Minified React error #300 twice at 09:56:06 UTC from bundle.js. Browser-extension errors were also present and are excluded from the application diagnosis.
