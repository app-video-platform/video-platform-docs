# BUG-010 — Marketing primary navigation overflows narrow screens

- Severity: Medium
- Status: Confirmed; not fixed in this test execution pass
- Related cases: MKT-001 through MKT-008; UX-015
- Role: CREATOR, Guest, USER and ADMIN confirmed.
- Environment: deployed frontend; Chrome viewport 375×812 and 390×844

## Reproduction

1. Open any marketing route, for example `/demo`, as the signed-in Creator.
2. Set the browser viewport to 375px wide.
3. Inspect the shared primary navigation without horizontally scrolling.

## Expected

Primary navigation and account actions remain reachable within the narrow layout, through wrapping or an appropriate navigation control.

## Actual

The header stays in a horizontal row extending to approximately 614px. Contact is partly clipped, and Dashboard and account controls are outside the initial viewport. All eight marketing routes reproduce the shared header overflow for both Creator and Guest. Guest header reaches approximately600px and clips Sign In/Register. Horizontal scrolling is required to reach those controls.

The homepage and About page also report wider total document bounds; the exact contributing sections have not yet been isolated. Their widths should not be attributed entirely to the header.

## Scope and limits

No responsive conformance is inferred from desktop passes. Other viewport sizes, zoom, and role-specific header controls require their own observations. No layout changes were made.

## User and Admin confirmation — 20 October 2026

Both additional signed-in roles reproduce the overflow on all eight marketing routes at 375×812. The Dashboard link spans approximately x398–471, outside the initial 375px viewport. The document width is 614px on six pages, 762px on About and 1062px on Home; the wider page bounds remain distinct from the shared navigation defect.

Desktop direct-load, reload and actual Back navigation independently retain the mapped page, shared navigation and footer under User and Admin. Creator Back navigation also passes on all eight pages. These controls do not make the narrow layout usable.

The existing consolidated browser batch contains `deployed-marketing-route-history-user-admin-width-matrix-2026-10-20`. Its geometry and actual route observations exclude transient Guest headers before authentication hydration. The temporary viewport was reset, the human account was restored to Creator and no application layout was changed.
